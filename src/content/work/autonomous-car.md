The autonomous car project is a testbed for perception, planning, and control within Elins
Research Club. I work on the software side: reading sensor data, turning it into a model of the
track, and translating that model into steering and speed decisions.

## Focus

The project is deliberately small in scale — a scaled vehicle, a controlled track, a fixed set of
rules — which makes it a useful place to test ideas that later apply to larger autonomous systems.

## Division work

I also serve as senior programmer in the robotics division, leading software development and
mentoring newer programmers.
